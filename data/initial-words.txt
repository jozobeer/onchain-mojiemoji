# Onchain mojiemoji — 初期語彙ドラフト
#
# 規模: 約 2250 語 (Issue #26 目標 1000-2000 をやや超過 — user review で trim 想定)
# ジャンル: 動詞 / 形容詞 / 名詞 (自然・季節・衣食住・文化・動植物・色彩・身体)
#         + 地名 (一般的) + 人名 (一般的な苗字・下の名前)
# 除外基準 (安全側): 暴力 / 性的 / 差別 / 政治 / 宗教 (特定宗教の固有名詞) / 商標
# Dictionary freeze 後は bytecode に永久残るため、選定は不可逆
#
# 1 行 1 単語。# で始まる行はセクションコメント (build-initial.ts が事前除去)
# 空行も build-initial.ts で除去される
# sanitize.ts が trim / dedup / 64-byte 上限 / 日本語 letter-only を強制
# 出力: data/initial-words.json (Dictionary.initialize 引数の hex bytes 配列)
